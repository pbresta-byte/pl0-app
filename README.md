# PL0 — Sarvato Bhadra Chakra Analyzer (consolidated)

The single Vedic muhūrta app. This repo supersedes the separate "muhurta gauge"
line — all its engines are merged here.

## Systems
- **Sarvato Bhadra Chakra** scoring — Vedha, Tārā Bala, Latta, Upagraha, dignity/retrograde strength, Pañcha Pakshi blend, reasoning shown inline
- **Pañchāṅga** — Tithi, Vāra, Nakṣatra, Yoga, Karaṇa + dosha checklist
- **Classical time windows** — Rāhu Kāla, Yama-Ghaṇṭa, Gulika, Abhijit muhūrta, Brāhma Muhūrta (Kalaprakasika p.175-77; Raman's Muhurtha), rescaled to true local sunrise/sunset
- **Parasara-hora activity layers** — 27 nakshatras × 10 activity profiles (marriage, travel, business, construction, agriculture, medicine, ceremony, vehicle, arts, daily work); Pushya universal-benefic-except-marriage; Chandrashtama with waxing-Moon neutralization; Nakshatra Panchaka avoidance
- **Pañcha Pakshi** — live 24h bird chart, real sunrise-driven periods
- **Auspicious Calendar** — day/night halves independently graded
- **Antara Chakra**, **Ashtakavarga**, **Vimshottari dasha**, **Ashtakoota matching**, **Muhurta Chintamani checks**, **Horary**, **Commodities**, **Remedies**

Every rule is transcribed from a named classical source or flagged as the app's own synthesis. See:
- `VERIFICATION.md` — rule tables cross-checked against ~45 extracted classical works (~20M chars)
- `CONSISTENCY.md` — day-grading engine audit (determinism, tier ordering, continuity sweeps)
- `BRIDGE.md` — MCP servers exposing these engines to external AI agents

## Use it now
Open [`www/index.html`](www/index.html) directly in any browser — single self-contained file, no build step.

## Android
```bash
npm install && npx cap sync android && cd android && ./gradlew assembleDebug
```
Or let CI build it: any push touching `www/` or `android/` runs the APK workflow.

## Project layout
- `www/` — the app (single HTML + PWA assets)
- `android/` — Capacitor wrapper (`assets/public` regenerated by `npx cap sync`)
- `muhurta-windows.js`, `parasara-activity.js`, `sbc-chakra-v2.js` — standalone module sources (also inlined into `www/index.html`)
